物品管家 · 使用细则

  1. 点右下角「＋ 添加物品」登记物品，名称必填，分类可以直接选预设，也可以自己输入。
  2. 填了有效期后，顶部「已过期 / 临期 / 总计」三张卡片会自动统计，点卡片只看对应的物品。
  3. 每件物品可以单独设置临期天数，默认是 3 天。
  4. 给物品填上金额，顶部「总金额」卡片会自动汇总；点它查看开销，并可用年 / 月 / 日筛选。
  5. 年 / 月 / 日三个筛选框既能下拉选择，也能直接键盘输入，清空即表示不限。
  6. 右上角「导出 / 导入」用来备份和恢复数据，换手机时先导出再导入即可。
